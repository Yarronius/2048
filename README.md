# 2048

Учебный клон игры [2048](https://github.com/gabrielecirulli/2048) на Java 17 и JavaFX.

Цель — собрать плитку **2048**, сдвигая поле стрелками и объединяя одинаковые числа. Если ходов больше нет — партия проиграна.

## Требования

- JDK 17 или новее
- Maven не обязателен: в репозитории есть [Maven Wrapper](https://maven.apache.org/wrapper/)

## Запуск

### IntelliJ IDEA

1. Откройте папку проекта и дождитесь импорта Maven.
2. Запустите `main` у класса `com.yarronius.numbersgame.Launcher`.

### Терминал

Из корня репозитория:

```bash
./mvnw javafx:run
```

Windows (cmd):

```bat
mvnw.cmd javafx:run
```

## Управление

| Клавиши | Действие        |
|---------|-----------------|
| Стрелки | ход             |
| Ctrl+Z  | отмена хода     |
| Esc     | выход           |

После победы или поражения можно начать новую партию или закрыть программу.

## Сборка

```bash
./mvnw -q compile
```

Точка входа — `com.yarronius.numbersgame.Launcher` (нужна, чтобы запускать JavaFX-приложение из JAR). Сама игра — класс `Game2048`.
